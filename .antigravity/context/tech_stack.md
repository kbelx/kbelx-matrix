# Tech Stack - KB_LAB

## Linguagem Principal
- **C++23**

## Sistema de Build
- **CMake** (v3.20+)

## Ferramentas e Bibliotecas Utilizadas
- `std::filesystem` - Para manipulação moderna de diretórios e arquivos cross-platform.
- `std::format` - Para formatação de strings com interpolação moderna.
- `windows.h` - Para manipulação de interface gráfica de erro (MessageBoxW) no ambiente Windows, com conversão de `UTF-8` para `Wide Char`.
- **Git** - Para versionamento utilizando a convenção *Conventional Commits*.
